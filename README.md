# 🌐 MA-Arquitectura  

Bienvenido al repositorio de **MA-Arquitectura**, la página web de mi estudio de arquitectura.  
El sitio busca transmitir la identidad del estudio, mostrar proyectos realizados y facilitar el contacto con potenciales clientes.  

## 📑 Estructura del sitio  
El sitio cuenta con **5 secciones principales**:  

1️⃣ **Inicio** → Imagen destacada con slogan.  
2️⃣ **Sobre mí** → Historia, visión y valores del estudio.  
3️⃣ **Proyectos** → Muestra de trabajos realizados, divididos en:  
   - Arquitectura Urbana  
   - Arquitectura Residencial  
   - Arquitectura Comercial  
4️⃣ **Servicios** → Detalle de los servicios que ofrece el estudio.  
5️⃣ **Contacto** → Información de contacto (email, teléfono, dirección y redes sociales).  

## 🛠️ Tecnologías utilizadas  
- **HTML5**  
- **CSS3**  
- **Node.js**  
- **Git**  
- **Bootstrap** (diseño responsive y componentes)  
- **Animate.css** (animaciones visuales)  

## ✨ Funcionalidades principales  
- 📌 **Barra de navegación dinámica** → Se adapta a todas las páginas y se convierte en menú *burguer* en pantallas móviles.  
- 📱 **Diseño responsive** → Optimizado para distintos tamaños de pantalla.  
- 🎨 **Animaciones** → Transiciones y efectos visuales con Animate.css.  

## 🚀 Instalación y uso  
Si querés clonar este proyecto localmente:  

```bash
git clone https://github.com/Mati-Azar/Sitio-Web-MA-Arquitectura.git
cd Sitio-Web-MA-Arquitectura
```

Luego abrí el archivo index.html en tu navegador.
